## 📌 Features

- ⚡ **Ultra-Fast Performance:** Bundled with Vite and built on Vue 3 Composition API.
- 🎨 **Minimalist Design:** Clean, distraction-free aesthetic with dark/light visual harmony.
- 📱 **Fully Responsive:** Tailored layout for mobile, tablet, and desktop viewports.
- 📑 **Data-Driven Architecture:** Decoupled JSON data layers for experience, projects, blogs, certifications, and technical proficiencies.

---

## 🛠️ Tech Stack

- **Framework:** Vue 3 (Composition API, `<script setup>`)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** Vercel / Custom Domain ([samayamahate.com.np](https://www.samayamahate.com.np))

---

## 🚀 Development Setup

```bash
# Clone the repository
git clone https://github.com/Samhubby/portfolio-vue.git
cd portfolio-vue

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
